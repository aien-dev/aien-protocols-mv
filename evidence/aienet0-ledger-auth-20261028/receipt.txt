Provisioning and invocation
- Generate coordinator transport/submitter/AN0V verifier and worker
  transport/executor test scalars with `openssl rand -hex -out FILE 32` in
  a private /dev/shm directory. Read only their public identities with
  `RUN keys --keys KEYS` and `SERVE keys --keys WKEYS`.
- PINS contains volunteer.ed25519 and executor.p256; WPINS contains
  coordinator.ed25519 and submitter.p256. Public values are in public-keys.txt.
- Generate two distinct disposable authority keys using
  `openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:P-256 -out FILE`.
  Pin their uncompressed SEC1 public keys in authority. Pin SHA-256 of raw
  submitter, volunteer transport and AN0V verifier public bytes as the role
  owner/node identities. policy pin is SHA-256 of quote's exact no-LF bytes.
  authority, quote and each mode's journal/authority retain public config.
- Set AUTHORITY, QUOTE, ISSUER_KEY and VERIFIER_KEY; existing carrier env is
  RUN SERVE LISTEN CONNECT KEYS PINS RECOMPUTE RECOMPUTE_SHA256 WKEYS WPINS WSTATE.
  LEDGER is the native binary above. LISTEN/CONNECT used fresh loopback ports,
  WSTATE was fresh for each run. No public listener, GPU or live 18091 access.
- From the repository root, with fresh E and the environment above:
    sh scripts/aienet0/settle-run.sh "$E" honest
    sh scripts/aienet0/settle-run.sh "$E" tampered-receipt
    sh scripts/aienet0/settle-run.sh "$E" tampered-attestation

  signatures, AN0B/MJR1/AN0V artifacts and journals are retained. All private
